# Taller PokéAPI

Proyecto Angular con NgModules para consumir la PokéAPI usando HttpClient y RxJS.

## Requisitos cumplidos

- HttpClientModule registrado en el módulo raíz.
- Interfaces TypeScript sin uso de `any`.
- Servicio con `switchMap`, `forkJoin` y `map`.
- Componente de lista con `ngOnInit`.
- Tarjetas con imagen, nombre y más de 4 propiedades.
- Estado de carga y estado de error visibles.

## Instalación

```bash
npm install
```

## Ejecutar

```bash
ng serve
```

Abrir en el navegador:

```text
http://localhost:4200
```
