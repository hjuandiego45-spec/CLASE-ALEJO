# Taller Angular Reactive Forms

Proyecto sencillo en Angular 19 para el taller del SENA sobre formularios reactivos

## Requisitos

- Node.js 20 o superior
- npm

## Instalación

Abra una terminal dentro de la carpeta del proyecto y ejecute

```bash
npm install
npm start
```

También puede usar

```bash
npx ng serve -o
```

La aplicación se abre en `http://localhost:4200`

## Funcionalidades

- Formulario creado con Reactive Forms
- Validaciones obligatorias por campo
- Validador personalizado para comparar contraseñas
- Mensajes de error después de interactuar con cada campo
- Botón deshabilitado mientras el formulario sea inválido
- Resumen de datos sin mostrar la contraseña
- Opción para mostrar u ocultar la contraseña
- Validador que impide espacios en el nombre de usuario
- Diseño sencillo, plano y blanco
